# Reference data

The catalogue contains 116 records grouped into 4 themes and 12 categories. The citation key connects each catalogue entry to the supplied BibTeX and citation lists.

| File | Contents |
| --- | --- |
| [catalogue.json](catalogue.json) | Citation records with classification, numbers and source information |
| [editorial.json](editorial.json) | Categories, themes and reading notes |
| [manuscript_reference_keys.json](manuscript_reference_keys.json) | Citation keys in catalogue order |
| [references.bib](references.bib) | Full bibliography in BibTeX |
| [references.csv](references.csv) | Filterable bibliography and citation locations |
| [verification.csv](verification.csv) | Verification status for each key |
| [source_checks.json](source_checks.json) | External record links and publication notes for checked entries |
| [metadata_corrections.json](metadata_corrections.json) | DOI additions from matched publication records |
